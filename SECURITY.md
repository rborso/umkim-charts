# Security policy

The app charts are Kubernetes packaging for upstream applications. Most
vulnerabilities in the applications themselves should be reported upstream.

Report a vulnerability privately through the umkim-thin repository:

<https://github.com/rborso/umkim-thin/security/policy>

Include the chart name/version, the affected image/component, a minimal
reproduction, and whether the issue is in the chart wiring or in upstream
software. Do not include live passwords, invite links, WireGuard keys or
session cookies.

This is a best-effort community project; there is no paid support or bug bounty.
